# Taste

## Design / UI

- Pushes back on UI that reads as generic "AI slop" — expects visual design to feel intentional and distinctive rather than template-driven/generated-looking, and wants a concrete metaphor carried through (e.g. the site should feel unique and literally book-like: spine stitching, ribbon bookmark, margin rules, perforated slip). Confidence: 0.7
- Expects horizontal balance: sections should use the full content width (flags narrow max-width blocks leaving dead space on the right) and paired columns should be equal, not asymmetric ratios. Confidence: 0.55
